# Collected batches

Place reviewed-for-Git submissions under `<bmw|competitors|social>/<collector>-<date>-<topic>/`. Each directory needs `source.json`, `records.jsonl`, optional `claims.jsonl`, and a short `notes.md` handoff. Source and claim review status remains pending until the orchestrator reviews the evidence.

Read [the handoff instructions and agent-prompt index](../README.md). No real data batches have been included in this package.
