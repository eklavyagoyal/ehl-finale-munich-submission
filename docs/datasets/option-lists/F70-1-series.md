## Legend

Model columns are always in the catalog's order: **118d · 120d · 116 · 120 · 123 xDrive · M135 xDrive**.

| Notation | Meaning |
|---|---|
| `S` | Standard equipment — catalog symbol ■ "Serienausstattung" |
| `O` | Optional equipment — catalog symbol □ "Sonderausstattung" (price in the price column) |
| `–` (in a model column) | Cell is empty in the catalog → treated as "not offered for this model (in this price variant)". The catalog legend does not define empty cells; this reading is inferred. |
| `–,–` (in price column) | "Sonderausstattung ohne Mehr-/Minderpreis" — option at no extra charge (catalog's own notation) |
| `Serie` (in price column) | Printed in the catalog for standard items |
| `1.900,– [1.596,64]` | EUR incl. 19 % MwSt. [EUR ohne MwSt.], German number format (`.` = thousands, `,` = decimals, `,–` = whole euros) |
| `↳` row | Conditional price variant of the code directly above (e.g. "In Verbindung mit M Sportpaket"), with its own per-model availability as printed |
| `n/s` | Not stated in the catalog |
| `(none printed)` | No code / no price is printed for that item (package-content and model-page tables) |
| `?` | Unreadable / ambiguous (not needed in any matrix — all symbols were legible; see Extraction notes) |
| ¹ ² ³ … | Catalog footnote markers. Footnote numbers restart on each catalog page; they are resolved in the section where they occur. |
